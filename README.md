# Importacion-y-exploracion-de-los-datos
Capítulo práctico sobre la importación y exploración inicial de los resultados de las Elecciones Municipales Provinciales de 2022.

**Fuente de datos:** INFOGOB.  
**Herramientas:** RStudio

El repositorio contiene el archivo R Markdown, el PDF del capítulo y la base de datos utilizada. Para reproducirlo, se deben mantener el archivo Excel y el R Markdown en la misma carpeta, abrir este último en RStudio y generar el documento.
